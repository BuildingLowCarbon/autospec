# Illustrations des paramètres

Ce dossier contient les illustrations statiques utilisées pour expliquer les paramètres de l’application.

Conventions recommandées :

- utiliser des noms descriptifs en minuscules avec des tirets, par exemple `building-width.svg` ;
- privilégier SVG pour les schémas et PNG/WebP pour les images matricielles ;
- importer les fichiers depuis les composants React plutôt que d’utiliser une URL absolue ;
- ne pas placer ici les images propres aux matériaux, produits ou macro-composants.

Exemple :

```js
import buildingWidthIllustration from '../assets/illustrations/parameters/building-width.svg';
```
