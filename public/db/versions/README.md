# Versions des bases de données

Les sous-dossiers et fichiers JSON horodatés sont créés automatiquement par le Dashboard lors du premier enregistrement :

- `components_unified/`
- `components_lignum_selected/`
- `lignum_product_tbz/`
- `tbz_materials/`
- `tbz_products_composites/`

Le format principal est `<nom>_AAMMJJ_HHmm.json`. En cas de plusieurs sauvegardes pendant la même minute, un suffixe numérique empêche tout écrasement.
